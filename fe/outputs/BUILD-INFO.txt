本次改动: 安卓端接入局域网联机（原生 UDP 插件），2.0 只在 Windows 可用的问题解决

安卓原生插件 (YiJianLanPlugin.java):
  - 用 Java 写的 Capacitor 本地插件（工程没有 Kotlin Gradle 配置，Java 省一层）。
    在 MainActivity.onCreate 里 registerPlugin(...) 注册。
  - 与 Windows 版行为完全一致：UDP 45455 广播房间（"YJA\t房间id\t房间名"，1.5 秒一次，
    按每张网卡的子网广播地址发送，并保留 255.255.255.255 兜底），
    收到 "YJS\t<json>" 就交给页面；插件本身不解析信令内容。
  - 对外 5 个方法：announce / rooms / send / inbox / status
  - 收 Wi-Fi 广播需要 CHANGE_WIFI_MULTICAST_STATE 权限并持有 MulticastLock，
    已在 AndroidManifest 中声明并在服务启动时获取。
  - 会话结束时释放 socket 与 MulticastLock（handleOnDestroy）。

Web 层 (net.js):
  - 新增 Capacitor 插件适配：探测到 Capacitor.Plugins.YiJianLan 时包成与桌面原生桥
    相同的接口，会话层完全不用区分外壳。
  - 桥可能比脚本晚注入，所以加了最多 1 秒的重试；仍拿不到就退回下一级传输。

传输优先级（两端统一）:
  注入式原生桥 -> Capacitor 插件 -> 同源 HTTP /lan/*（桌面） -> BroadcastChannel（同机） -> 隐藏入口
