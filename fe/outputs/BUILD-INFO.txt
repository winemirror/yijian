Windows 桌面版:
  A. 浏览器兜底链
     Edge（4 个安装位置 + 注册表 App Paths\msedge.exe）
     → Chrome → Brave → Vivaldi → Opera → 360 → QQ 浏览器
     → 系统默认浏览器（ShellExecute，普通标签页打开）
     精简版 Windows 没有 Edge 时不再直接失败。
  B. 工作目录兜底
     先试 exe 同级目录，不可写（Program Files、只读共享、被杀软隔离的下载目录）时
     自动改用 %LOCALAPPDATA%\YiJian，日志与资源页面都写在那里。
  C. 诊断
     一个浏览器都找不到时，弹窗给出可复制的本地地址，同时把地址放进剪贴板，
     并写入 YiJian-data\launcher.log。
  说明: 首次打开"无法访问"的两个根因（HTTP.sys URL 预留在首启未就绪、只读目录写不进
        资源）都已消除。服务仍是 127.0.0.1 随机端口，no-store，正确的 MIME 类型。
        退出判定只看本次启动的那个浏览器进程，不会被用户已经开着的其它浏览器拖住。

Android 版:
  P0. index.html 顶部加入纯 ES5 兼容守卫
      内核过旧时显示"浏览器版本过低"提示卡（并隐藏主界面），不再白屏；
      另附 <noscript> 提示。守卫脚本自身就是 ES5，能被它要提醒的最老内核执行。
  P1. CSS 兜底
      aspect-ratio → padding-top:111.1111% 占位（9:10 棋盘）
      inset:0 → top/right/bottom/left 四边
      place-items → flex 居中
      clamp() → 前一行写固定值，clamp 只作渐进增强
  P2. 现代语法清理
      移除全部 ?. / ?? / Array.prototype.at / Element.replaceChildren；
      flex 容器的 gap 改为子元素外边距（所有内核都认），
      grid 容器同时保留 grid-gap（Chrome 57-83 走别名，现代内核走 gap）。
  实测: app.js 最低解析等级 ES2017（Chrome 55），守卫脚本 ES5；
        Android 7（WebView 51-55）即可解析，更老的内核由 P0 守卫给出提示。
