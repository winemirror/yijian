本次改动: 修复"电脑与手机无法联机"的真正根因

根因:
  net.js 的桌面 HTTP 通道里，base 是 "lan/"，而各方法传的是 "/lan/inbox" 这样的
  绝对路径，拼出来是 "lan//lan/inbox"，C# 路由匹配不到就返回 404。
  结果桌面版页面调用 C# 的每一个请求全部 404：
    /lan/announce 404  -> 电脑其实从未广播过房间
    /lan/rooms    404  -> 电脑看不到任何房间
    /lan/inbox    404  -> 电脑收不到手机发来的连接请求，永远不会应答
    /lan/send     404  -> 电脑发不出应答
  手机 ↔ 手机走的是原生插件、不经过这条 HTTP 通道，所以一直正常。
  现象（手机看不到电脑房间、手工输 IP 也连不上）由此全部解释。

修复:
  - httpTransport 内所有路径改为相对形式（send / announce / inbox / rooms），
    不再自己带 "/lan/" 前缀
  - poll 增加 waitMs 参数：网络自检用 wait=0，不再卡 25 秒长轮询
  - 「房间日志」移出 #netActive，未进房间时也可见（否则自检结果写进隐藏元素）
  - build.ps1 编译失败时抛错，避免静默留下旧 exe
