本次改动: 修复观战者只能看到房主那一手棋

根因:
  房主自己走子时 netSend 是广播，观众能看到；但对手走子时，那条 move 只发给
  房主（对手只有房主一条连接），房主没有转发给观众。于是观众要等房主再走一步
  才看到棋盘变化 —— 正好表现为"一回合才更新一次"。

修复:
  - net.js 新增 sendExcept(peerId, message)：发给除指定对端之外的所有人。
  - app.js 新增 netRelayFromHost()：房主收到任一玩家发来的对局事件后，
    用 sendExcept 转发给其余对端。覆盖 move / chat / resign / newGame /
    undoReq / undoOk / undoNo / sync。
  - 房主自己的事件仍走 netSend 广播，两条路径不会重复送达。

验证:
  verify-net 新增两条：
    * sendExcept 只发给除发起者以外的对端
    * 房主收到某个玩家的 move 后，会以该玩家 id 调用 sendExcept 转发
  5 个套件全绿；perft(3) = 79666
  APK 的 assets/public 与 www/ 逐文件哈希一致
  桌面版已重建（重建前需先关闭正在运行的弈鉴）
